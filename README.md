# ⭐ 星星工作台

> 一颗星星，装下我们的小宇宙 ✨

一个**轻量、离线可用、零注册**的私人任务管理应用。打开网页即用，可以像原生 App 一样装到手机桌面。

## ✨ 功能特性

- 📋 **任务管理**：新建 / 编辑 / 删除 / 状态流转（待办 → 进行中 → 完成）
- 🗂️ **五大分类**：工作、个人、学习、健康、其他，还有专属的「伟大的爱情」❤️
- 🗓️ **日历视图**：按日期查看和安排任务
- 📊 **统计报表**：完成率、分类占比、趋势一目了然
- 🗃️ **存档**：历史任务自动归档
- 📴 **完全离线**：Service Worker 缓存，断网 / 飞行模式照常使用
- 🔒 **数据本地存储**：任务只存在自己手机里，不联网、不共享、隐私安全
- 📤 **导出 / 导入**：JSON 一键备份迁移
- 📱 **PWA 应用**：桌面图标、全屏启动，体验与原生 App 无异
- 💖 **甜蜜弹窗**（专属版）：完成任务弹「宝贝真棒！」，新建任务弹「宝贝辛苦了，回家亲亲你」……
- 🎉 **里程碑彩蛋**（专属版）：累计完成 20 / 50 / 99 件任务触发专属鼓励；100、111、188、200、222、520、1314 等趣味数字随机掉落心灵鸡汤

## 📲 安装到手机（PWA）

**iPhone（Safari）**
1. 用 Safari 打开上方地址（不要用微信内置浏览器）
2. 等待页面加载 1~2 秒（让离线缓存装好）
3. 点击底部**分享按钮** → **添加到主屏幕**
4. 桌面上出现 ⭐ 星星图标，点开即全屏使用

**Android（Chrome）**
1. 用 Chrome 打开上方地址
2. 点击菜单 **⋮** → **添加到主屏幕** / **安装应用**

> 首次打开需联网，之后即可离线使用。

## 🛠️ 技术栈

- 纯原生 **HTML + CSS + JavaScript**（单文件，零依赖）
- **PWA**：manifest.json + Service Worker 离线缓存
- **数据**：浏览器 localStorage（本地存储）

## 📁 项目结构

```
├── index.html            # 应用本体（所有代码内嵌）
├── manifest.json         # PWA 清单（全屏、图标、主题色）
├── sw.js                 # Service Worker 离线缓存脚本
├── apple-touch-icon.png  # iOS 桌面图标
└── README.md             # 本说明
```
